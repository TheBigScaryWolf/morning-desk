# Morning Desk

Personal crypto morning dashboard: open `index.html` (or the GitHub Pages link).

- Live in the browser: BTC, Fear & Greed, open interest, long/short, stablecoin flows, chain TVL, Hyperliquid, BTC ETF flows.
- `intel.json` is rewritten by a scheduled Claude crawl: morning brief, L1/L2 news, token sales (CoinCarp), ETH ETF flows, and weekly fundraising (Mondays).

BTC ETF data: The Commoner Bitcoin ETF Tracker by TFTC (CC BY 4.0).
